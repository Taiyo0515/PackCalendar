# 02 仕様

## 1. 用語

| 用語 | 意味 |
|---|---|
| バッグ | 予定で使う入れ物。名前と色を持つ |
| 持ち物 | 移し忘れたくない物。名前と写真（任意）を持つ |
| 基本セット | そのバッグを使うとき、いつも必要な持ち物の集まり |
| 位置 | 持ち物がある場所の記録。自宅・身につける・各バッグ・不明のどれか |
| 必要な物 | ある予定で必要な持ち物。基本セット＋追加−除外 |
| 今回だけ | その予定だけで必要な物。持ち物として登録しない文字列 |
| 準備 | 同じ日に同じバッグで続く予定をまとめたもの。準備の単位 |
| 移す物 | 準備で必要な物のうち、そのバッグにも「身につける」にもない物 |

## 2. 画面の構成

タブは3つです。

| タブ | 内容 |
|---|---|
| カレンダー | 準備カードと月のカレンダー。アプリ起動時に開く |
| 持ち物 | バッグと持ち物の一覧 |
| 設定 | 外観、カレンダー、準備、通知、データ |

スマホでは画面下にタブバーを置きます。PC（幅 900px 以上）では左端に縦のタブを置き、カレンダーの右に選択日のパネルを常に表示します。

## 3. カレンダー

### 3.1 ヘッダー

- 左に「2026年9月」。
- 右に「今日」（表示中の月が今月でないときだけ）、前月、翌月の各ボタン。
- 月の移動は左右スワイプ（スマホ）、ボタン、キーボードの ←→ でも行える。

### 3.2 準備カード

- ヘッダーの下に置く。**48時間以内に始まる準備がなければ表示しない。**
- 対象は、今より後に始まる最初の準備。
- 移す物があるとき：

```
明日 9:00  大学で作業                 リュック
ミニバッグから   財布・鍵
自宅から         学生証
場所不明         イヤホン
今回だけ         教科書
```

  - 1行目：いつ（今日・明日・9/30(水)）、時刻、予定名、バッグ名（バッグの色）。
  - 2行目以降：移動元ごとに1行。順序は「バッグ → 自宅 → 場所不明 → 今回だけ」。
  - 行は最大4行。超える分は最後の行を「ほか3点」にまとめる。
- 移す物がないとき：1行だけ表示する。`✓ 明日 9:00 大学で作業 · リュック`
- カードをタップすると、その準備を対象にしたバッグ画面を開く（§5.2）。

### 3.3 月のカレンダー

- 6週×7日。週の始まりは設定（日曜・月曜）に従う。
- 各マスの表示：
  - 上に日付の数字。日曜と祝日は赤、土曜は青。今日は数字を塗りつぶした丸で囲む。
  - その下に帯を並べる。順序は「祝日名（赤）→ 終日の予定 → 時刻の早い予定」。
  - 予定の帯はバッグの色で塗り、予定名を白文字で出す。バッグなしの予定は灰色。
  - 帯に入りきらない予定名は、省略記号なしで右端を切る（TimeTree と同じ）。
  - マスに収まらない件数は、最後の帯の代わりに「+2」と出す。
  - 前月・翌月の日付は薄く表示する（予定は表示する）。
- マスをタップすると、その日を選択する。
  - スマホ：日のシート（§3.4）を開く。
  - PC：右側の日パネルをその日に切り替える。
- 右下の「＋」ボタンで、選択中の日（未選択なら今日）に予定を追加する。

### 3.4 日のシート（PC では日パネル）

- 見出し：`9月21日 月曜日`。祝日なら横に祝日名を赤で出す。右に「＋」。
- 予定を時刻順に並べる。1行の内容：
  - 左：開始時刻と終了時刻の2段（終日なら「終日」）。
  - 色の縦線（バッグの色）。
  - 予定名と、その下にバッグ名（小さい灰色の文字）。
- 予定がない日は何も表示しない（「予定はありません」とも書かない）。
- 予定をタップすると予定の詳細（§3.5）を開く。

### 3.5 予定の詳細

- 上部：戻る（←）、編集。
- 予定名（大きく）。
- 日時：開始と終了を「2026年9月17日(木) / 13:30 › 2026年9月17日(木) / 14:30」の形で表示する。終日なら日付だけ。
- 行（値があるものだけ表示）：
  - バッグ：色付きの名前。
  - 持ち物：必要な物を「・」区切りで表示する。今回だけの物も含める。
  - 繰り返し：「毎週 月・水・金」など。
  - メモ。

### 3.6 予定の入力

TimeTree の入力画面と同じ構成にします。

- 上部：閉じる（×）と「保存」。予定名が空のとき、保存は押せない。
- 予定名：大きな入力欄。新規作成時は自動でフォーカスする。
- 終日：スイッチ。
- 開始：日付と時刻。終了：日付と時刻。
  - 終了は開始の1時間後を初期値にする。開始を変えたら、終了も同じ長さを保ってずらす。
  - 終日のときは時刻を隠す。
- バッグ：横に並んだチップから1つ選ぶ。もう一度タップすると解除できる。
- 追加の項目（タップで開く）：「繰り返し」「持ち物」「メモ」。値が入っている項目は最初から開いておく。
  - 繰り返し：なし・毎日・毎週・毎月。毎週なら曜日を複数選べる（初期値は開始日の曜日）。終了日は任意。
  - 持ち物：バッグの基本セットをチップで表示する。タップすると除外（取り消し線）になり、もう一度で戻る。「＋」で基本セット以外の持ち物を追加する。「今回だけ」の文字を入力して Enter で追加する。
  - メモ：複数行。
- 編集時は画面の最下部に「予定を削除」を置く。
- 同名の予定からの補完：新規作成時に、入力した予定名が過去の予定名と完全に一致したら、まだ触っていない項目にだけ、そのうち最新の予定のバッグ・開始時刻・終了時刻（長さ）を入れる。
- 繰り返し予定を編集して保存するとき、または削除するときは「この予定のみ」「すべての予定」を選ばせる。
  - この予定のみ：その日の変更として保存する。元の予定は変えない。
  - すべての予定：元の予定を変える。日付は元の開始日を保ち、時刻・長さ・その他の項目を反映する。
- 入力中に閉じるときは確認しない（入力を捨てる）。

## 4. 準備の計算

### 4.1 必要な物

- 予定の必要な物は「バッグの基本セット ＋ 追加 − 除外」。除外が優先。
- バッグのない予定は準備の対象外。

### 4.2 準備のまとめ方

- 予定を開始時刻の順に並べ、同じ日に同じバッグの予定が続く間は1つの準備にまとめる。
  - 別のバッグの予定や、バッグなしの予定をはさむと、別の準備になる。
  - 日が変われば、別の準備になる。
- 準備の開始時刻は、まとめた予定のうち最初の開始時刻。
- 準備の必要な物、今回だけの物は、まとめた予定の和集合。
- 準備カード・通知・ウィジェットに出す予定名は、最初の予定の名前。

### 4.3 移す物

- 必要な物のうち、位置がそのバッグでも「身につける」でもない物。
- 移動元の分類：
  - 別のバッグにある →「（バッグ名）から」
  - 自宅 →「自宅から」
  - 不明 →「場所不明」
- バッグに入っているが不要な物は出さない。

### 4.4 自動記録

- 設定「予定の時刻に準備済みにする」がオンのとき、準備の開始時刻を過ぎたら、その準備の必要な物の位置をバッグにする。
- ただし、開始時刻より後に位置を変えた持ち物は対象外（あとから行った手動の修正を上書きしない）。
- アプリを閉じていた間の準備は、次に開いたとき時刻の順に反映する。反映はアプリの起動時、画面への復帰時、1分ごとに行う。
- 今回だけの物は位置を持たないので記録しない。準備の開始時刻を過ぎたら表示から消える。

### 4.5 手動の修正

- バッグ画面で持ち物をタップすると、出し入れされる。
- 持ち物の編集画面で、位置を直接選べる。
- 位置を変える操作・削除のあとには「元に戻す」を約5秒表示する。

## 5. 持ち物タブ

### 5.1 一覧

- 「バッグ」の欄：色の丸、名前、基本セットの数。タップでバッグ画面を開く。見出しの右に「＋」。
- 「持ち物」の欄：写真（ない場合は頭文字の丸）、名前、右に位置（灰色）。タップで持ち物の編集を開く。見出しの右に「＋」。
- どちらも空なら、欄の見出しと「＋」だけを表示する。

### 5.2 バッグ画面

- 上部：戻る、バッグ名、編集（名前・色・削除）。
- 3つの欄に分ける。
  1. **足りない**：基本セットのうち、このバッグにない物。準備カードから開いたときは、その準備で移す物と今回だけの物。
  2. **入っている**：位置がこのバッグの物。
  3. **ほか**：上の2つ以外の持ち物（右に位置を表示）。
- 行をタップすると出し入れする：
  - 足りない・ほか → このバッグに入れる。
  - 入っている → 自宅に出す。
- 行の右端のピンで、基本セットに入れる・外すを切り替える。基本セットに入っている物は、ピンを塗りつぶして表示する。
- 空の欄は表示しない。
- PC ではドラッグでも出し入れできる：左の列が「足りない・入っている」、右の列が「ほか」。
- 今回だけの物は行として表示するが、操作はできない。

### 5.3 持ち物の登録・編集

- 写真：丸い枠をタップして撮影、または写真を選ぶ。長辺 240px に縮小して保存する。
- 名前：必須。
- 位置：チップから1つ選ぶ（自宅・身につける・各バッグ・不明）。新規の初期値は自宅。
- 基本セット：どのバッグの基本セットに入れるかを、バッグのチップで複数選ぶ。
  - 新規登録で位置にバッグを選ぶと、そのバッグの基本セットも自動で選ぶ（選んだ後に外すことはできる）。
- 新規登録のボタンは「保存」と「続けて追加」。続けて追加は保存後に名前と写真だけを空にし、名前の欄にフォーカスを戻す。場所と「いつも入れるバッグ」は引き継ぐ（バッグの中身を続けて登録しやすくするため）。
- 編集時は最下部に「削除」。削除すると、基本セットと予定の追加・除外からも取り除く。

### 5.4 バッグの登録・編集

- 名前（必須）と色（7色から選ぶ）。
- 削除すると、その予定のバッグ指定を外し、中にあった持ち物の位置を「不明」にする。

## 6. 設定

| 項目 | 内容 |
|---|---|
| 外観 | アプリ：自動・ライト・ダーク。ウィジェット：自動・ライト・ダーク（iPhone アプリのときだけ表示） |
| カレンダー | 週の始まり：日曜・月曜。祝日を表示：オン・オフ |
| 準備 | 予定の時刻に準備済みにする：オン・オフ |
| 通知 | 通知：オン・オフ。前日の時刻、当日の時刻（それぞれオフにできる）。Web では初回に招待コードを入れて接続する |
| データ | 書き出す、読み込む、すべて削除 |

- 初期値：週の始まり＝日曜、祝日＝オン、自動記録＝オン、通知＝オフ（前日 21:00・当日 7:00）、外観＝自動。
- 画面の最下部に小さくバージョン番号を出す。

## 7. 祝日

- 日本の国民の祝日を端末内で計算する（通信しない）。
- 対象は 2000〜2099 年。振替休日と国民の休日を含む。2019年・2020年・2021年の特例（即位関連、五輪による移動）も含める。
- 設定がオフのときは、カレンダー・日のシート・ウィジェットに出さない（日曜の赤は祝日と関係なく出す）。

## 8. 通知

- 通知は準備ごとに、前日の指定時刻と当日の指定時刻に出す。
  - 移す物がない準備は通知しない。
  - 指定時刻が準備の開始時刻より後になる場合は出さない。
- 文面：
  - タイトル：`明日 9:00 大学で作業`（当日なら「今日」）。
  - 本文：`リュック｜ミニバッグから 財布・鍵／自宅から 学生証／今回だけ 教科書`
- 14日先までの準備について、自動記録を前提に、先の位置を予測しながら通知の予定表を作る。最大60件。
- 予定・持ち物・位置・設定を変更するたびに、予定表を作り直して登録し直す。
- Web：Cloudflare Worker に予定表を送る。送信に失敗したら、次の変更時と起動時に再送する。
- iPhone アプリ：ローカル通知として予約する（最大60件）。

## 9. ウィジェット（iPhone アプリ）

### 9.1 準備リスト（2×2・small）

```
明日 9:00
リュック              ← バッグの色
ミニバッグから
 財布・鍵
自宅から
 学生証
```

- 48時間以内に始まる最初の準備を表示する。時刻を過ぎたら次の準備に切り替わる。
- 移す物がなければ「✓ 準備OK」。
- 準備がなければ「予定なし」だけを表示する。
- 行が入りきらないときは、最後の行を「ほか◯点」にする。

### 9.2 カレンダー（4×4・large）

- 今月の月カレンダー。上に「9月」、6週×7日。
- 各マスに日付と予定の帯（予定名つき、最大2本。3件以上あれば2本目を「+N」にする）。
- 今日の数字は丸で囲む。日曜・祝日は赤、土曜は青。

### 9.3 共通

- タップするとアプリが開く。
- 外観は設定の「ウィジェット」に従う（自動は端末の設定に合わせる）。
- アプリで変更するたびに、ウィジェットの表示データを更新する。

## 10. データ

- 保存は端末内（IndexedDB）。サーバーに送るのは通知の時刻・文面・購読情報だけ。
- 書き出し：写真を含めて1つの JSON ファイル。
- 読み込み：件数を確認してから、現在のデータと置き換える。
- iPhone アプリ：1日1回、「ファイル」アプリから見える場所に自動でバックアップする（最新7日分）。
- 旧版（v2）の保存データがあれば、初回起動時に変換して引き継ぐ。旧版のバックアップも読み込める。
- 別のタブでの変更は、即座に表示へ反映する。
