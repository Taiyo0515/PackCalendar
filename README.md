# PackCalendar

予定に使うバッグと、記録上の持ち物の位置から、**今回必要な準備だけ**を表示するカレンダーです。

**[アプリを開く](https://taiyo0515.github.io/PackCalendar/)**

月間カレンダー、予定と繰り返し予定、バッグの基本セット、予定ごとの持ち物の追加・除外、準備完了時の位置更新に対応しています。Android・iPhone・PCのブラウザで利用できます。

データは使っている端末のブラウザに保存され、端末間で自動同期されません。機種変更や別ブラウザへの移行には、アプリの「設定」→「書き出す」「読み込む」を使ってください。写真を含むバックアップファイルには個人的な記録が入るため、公開リポジトリに追加しないでください。

公開版はHTTPSで配信され、一度読み込むとオフラインでも起動できます。Androidではブラウザのメニュー、iPhoneではSafariの共有メニューからホーム画面に追加できます。通知はアプリ内のプレビューです。

このリポジトリには、GitHub Pagesでそのまま配信する静的ファイルを置いています。ローカルで見る場合は、Python 3で次のコマンドをこのフォルダーで実行し、<http://localhost:4173/> を開いてください。

```sh
python -m http.server 4173 --bind 127.0.0.1
```

`index.html` の直接ダブルクリックではなく、HTTPサーバー経由で開きます。公開版とローカル版の保存データは別です。公開版に移すときは、ローカル版の「書き出す」から復元してください。
