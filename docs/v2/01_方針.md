# 01 方針

## 1. 作るもの

**予定にバッグを付けておくと、次の外出で「どこから何を入れるか」だけが分かるカレンダー。**

使い方は大きく2つだけです。

1. **予定を入れる**：普通のカレンダーと同じように入力し、バッグを1つ選ぶ。
2. **準備を知る**：通知、ウィジェット、カレンダー上部の1枚のカードで、移す物だけを見る。

準備の完了は操作しなくても、予定の開始時刻に自動で記録されます。

## 2. 絶対条件

1. **シンプル**：1画面の目的は1つ。装飾はしない。
2. **分かりやすい**：見れば分かることは書かない。説明文や見出しを増やして分かりやすくしようとしない。
3. **使いやすい**：よく使う操作ほど少ないタップで済ませる。標準的なカレンダーアプリ（TimeTree・iOS 純正）と同じ操作感にする。
4. **安定**：表示のちらつき・二重登録・状態のずれを起こさない。

## 3. UI の禁止事項

- 入力欄以外の文字を選択できる状態にしない。長押しでのコピーメニューも出さない。
- 飾りのイラスト、英語の見出し、キャッチコピー、補足の一言を置かない。
- 同じ情報を2か所に同時に表示しない。
- 自明なラベル（「必須」「任意」「〜してください」など）を書かない。
- スマホのカレンダーで、予定を点だけで表示しない。**予定名を必ず表示する。**

## 4. 判断基準

新しい要素を足すときは、次の順に確かめます。

1. 持ち物について考える量が減るか。
2. 毎日の操作が増えないか。
3. 画面の情報量が増えないか。増えるなら、何かを減らせるか。
4. 標準的なカレンダーアプリの操作と矛盾しないか。

## 5. 過去の資料からの取捨選択

### 採用する

| 項目 | 出典 |
|---|---|
| 予定 → バッグ → 必要な物 → 記録上の位置 → 移す物、という核の流れ | 思想・仕様書 |
| 差分だけを見せる。不要な物を出す指示はしない | 思想・仕様書 §13・§32 |
| 予定の開始時刻に準備済みとして自動記録する | サイト評価 §4.1 |
| 同じ日に同じバッグで続く予定は、1回の準備にまとめる | 設計レビュー §2.4 |
| 「身につける」場所（スマホなど、どのバッグでも準備済みとみなす） | 設計レビュー §2.3 |
| 今回だけの持ち物（持ち物として登録しない文字列） | 設計レビュー §5 |
| 同じ名前の過去の予定から、バッグと時刻を自動で入れる | サイト評価 §4.3 |
| 準備の表示は48時間先まで | 設計レビュー §1 |
| 表示は移動元ごとにまとめる（「ミニバッグから 財布・鍵」） | サイト評価 §4.4 |
| バッグ画面で中身をタップして出し入れする。PC はドラッグにも対応 | サイト評価 §9 |
| 持ち物は写真（任意）と名前だけで登録できる | サイト評価 §4.5 |
| 登録時にバッグを選ぶと、位置と基本セットを同時に設定する | 設計レビュー §2.5 |
| IndexedDB に保存。写真も端末内 | 設計レビュー §6 |
| Web は Cloudflare Worker の Web Push、iPhone はローカル通知 | サイト評価 §10 |
| SideStore で入れる未署名 ipa | サイト評価 §11 |

### 今回は作らない（シンプルさを優先して捨てる）

| 項目 | 理由・代わり |
|---|---|
| タグ・カテゴリ | 色はバッグで付く。入力補助は同名予定からの補完で足りる |
| 曜日ごとの既定バッグ（ルール） | バッグ付きの繰り返し予定で同じことができる |
| 名前付きの場所（職場ロッカーなど） | 場所は「自宅・身につける・各バッグ・不明」だけで足りる |
| 準備カードの項目ごとのチェック、「すべて準備できた」 | 自動記録にする。直したいときはバッグ画面で出し入れする |
| 移動履歴、計測、「忘れた」ボタン | 直前の操作は「元に戻す」で取り消せる。位置は持ち物画面で直せる |
| 持ち物のアイコン選択、持ち物・バッグのメモ | 写真か頭文字で見分けられる |
| サンプルデータ、初回案内 | 空のカレンダーから普通に使い始められる |
| 論理削除・更新日時（同期の準備） | 同期を作るときに追加する |
| 初代（localStorage 版）のデータ移行 | 旧 v2（IndexedDB 版）のデータとバックアップからの移行だけ行う |
| Codemagic | GitHub Actions でビルドする |
| 外部カレンダー連携、AI 認識、入れ子のポーチ | 将来 |

## 7. 対象環境

- Web（GitHub Pages、PWA）：iPhone の Safari、Android の Chrome、PC の Chrome・Edge・Safari・Firefox。
- iPhone アプリ（Capacitor）：iOS 15 以上。ウィジェットは iOS 17 以上。
- 画面幅：320px〜。PC では幅に合わせて右側に日付パネルを出す。
