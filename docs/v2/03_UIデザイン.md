# 03 UIデザイン

参考：`references/timetree1〜4.png`（TimeTree の月表示、日のシート、予定の詳細、入力画面）。

## 1. 原則

1. **中身が主役**：面は背景色と区切り線だけで作る。影・グラデーション・イラスト・角丸カードの重ね合わせは使わない（例外：シートとボタン）。
2. **文字は3段階**：本文、補助（灰色）、見出し（大きく太く）。それ以外の大きさを作らない。
3. **色は意味にだけ使う**：バッグの色、日曜・祝日の赤、土曜の青、操作の緑。
4. **ラベルは最小限**：アイコンや配置で分かるものに文字を足さない。入力欄のプレースホルダーは、何を入れる欄か分からない所にだけ置く。
5. **純正の部品**：スイッチ・シート・グループ化したリストなど、iOS 標準と同じ形と動きにする。
6. **選択禁止**：`user-select: none` を全体にかけ、`input`・`textarea` だけ許可する。`-webkit-touch-callout: none`、タップ時のハイライトも消す。

| `--bg` | #FFFFFF | #111111 | 画面の背景 |

| `--sheet` | #FFFFFF | #1C1C1E | シートの背景 |
| `--fill` | #E9E9EE | #2C2C2E | チップ、押下時 |
| `--line` | #E3E3E8 | #2A2A2C | 区切り線 |
| `--text` | #111111 | #F2F2F2 | 本文 |
| `--sub` | #8A8A8E | #8E8E93 | 補助 |
| `--faint` | #C7C7CC | #48484A | 前月・翌月の日付 |

## 3. 文字

- 書体：`-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif`
- 数字は等幅（`font-variant-numeric: tabular-nums`）。

| 種類 | 大きさ / 太さ | 用途 |
|---|---|---|
| 大見出し | 28px / 700 | 月（「2026年9月」）、予定名の入力、詳細の予定名 |
| 見出し | 17px / 700 | シートの見出し、欄の見出し |
| 本文 | 16px / 400〜600 | リスト行、入力 |
| 補助 | 13px / 400 | 位置、時刻の2段目、バッグ名 |
| 帯 | 11px / 700（PC 12px） | カレンダーの予定名 |

## 4. 部品

| 部品 | 形 |
|---|---|
| リスト行 | 高さ 52px 以上。左に丸いアイコン（写真・色の丸・頭文字）、中央に文字、右に補助の値か「›」。区切り線は文字の左端から始める |
| グループ | 角丸 12px の `--bg2` の面に行を並べる（設定・持ち物）。見出しは面の外、左上に補助色で |
| チップ | 高さ 34px、角丸 17px、`--fill`。選択中は `--accent` の塗りと白文字。バッグのチップは左に色の丸 |
| ピル（日時） | 高さ 36px、角丸 8px、`--bg2`。中にネイティブの date/time 入力 |
| スイッチ | iOS 標準と同じ 51×31px |
| 丸ボタン | 「＋」：直径 56px、`--accent`、白い＋。カレンダー右下に固定 |
| シート | 下から出る。上端の角丸 14px、つまみ（36×5px）。背景を暗くする。PC では中央のダイアログ（最大幅 520px） |
| トースト | 画面下、タブバーの上。黒地に白文字と「元に戻す」 |
| セグメント | 2〜3択の切り替え（外観、週の始まり）。iOS 標準の形 |

タップの領域は最低 44×44px にします。

## 5. 画面

### 5.1 カレンダー（スマホ）

```
┌──────────────────────────────┐
│ 2026年9月            今日 ‹ ›  │ ← 大見出し
│ ┌────────────────────────────┐ │
│ │明日 9:00 大学で作業  リュック│ │ ← 準備カード（--bg2 の面）
│ │ミニバッグから  財布・鍵      │ │
│ │自宅から        学生証        │ │
│ └────────────────────────────┘ │
│ 日  月  火  水  木  金  土     │ ← 補助の色。日=赤 土=青
│────────────────────────────────│
│ 30  31   1   2   3   4   5     │
│         ▇防災 ▇2,3限    ▇駿横   │ ← 帯（予定名）
│────────────────────────────────│
│  …（6週ぶん、残りの高さを等分）  │
│                           (＋) │
├──────────────────────────────┤
│  カレンダー    持ち物    設定   │ ← タブバー
└──────────────────────────────┘
```

- 月のカレンダーは、残りの高さをすべて使い、6週で等分する。
- マスの区切りは横線だけ（縦線は引かない。TimeTree と同じ）。
- 選択中の日は、マスの背景を `--bg2` にする。

### 5.7 設定

iOS の設定アプリと同じ、グループ化したリスト。値の選択はセグメントまたはスイッチで、その場で切り替える（別画面に遷移しない）。

## 6. PC のレイアウト（幅 900px 以上）

```
┌────┬───────────────────────────┬──────────────┐
│ 📅 │ 2026年9月          今日 ‹ › │ 9月21日 月曜日 │
│ 🎒 │ [準備カード]                 │ 13:30 髪を切る │
│ ⚙ │ 月のカレンダー               │              │
└────┴───────────────────────────┴──────────────┘
```

- 左のタブは幅 72px、アイコンと小さい文字。
- 日パネルは幅 320px。予定の詳細と入力は中央のダイアログで開く。
- 持ち物タブと設定タブは、中央の幅を最大 720px にする。

## 7. ダークモード

- アプリの外観：自動（`prefers-color-scheme`）・ライト・ダーク。`html[data-theme]` でトークンを切り替える。
- iPhone アプリでは、同じ設定をネイティブ側にも伝えて、ステータスバーの文字色とシートの背景を合わせる。
- ウィジェットは別の設定で、自動・ライト・ダークを選ぶ。

## 8. 動き

- シート：下から 250ms で出す（ease-out）。PC のダイアログはフェードだけ。
- 月の切り替え：アニメーションしない（ちらつきを避ける）。
- `prefers-reduced-motion` のときは、すべてのアニメーションを止める。
- 画面の更新は、変わった部分だけ描き直す。1分ごとの再計算で、表示中のシートやスクロール位置を失わない。
