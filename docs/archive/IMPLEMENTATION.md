## 必須の改修

- [x] Vite / TypeScript / React、純粋なドメイン処理、プラットフォーム層へ移行。
- [x] IndexedDB / Dexie に状態と写真Blobを保存。旧localStorageとv1バックアップを破壊せず移行。写真240px。競合・破損・保存失敗・写真込みバックアップを検証。
- [x] ホームに可変高の準備カードとカレンダーを統合。48時間以内の1単位、最大3行、準備なし1行。PCは予定一覧を右列。
- [x] ナビゲーションをホーム / 持ち物 / 設定の3つに。装飾見出し・重複パネル撤去。常設予定追加。
- [x] 準備自動完了、移動履歴とsource、永続的な取消、忘れ物記録。閉じていた間は次の起動で時系列適用。手動修正を過去予定が上書きしない。
- [x] 同じバッグの連続予定を準備単位としてまとめ、移動元ごとの文面、一時持ち物、不明位置、身につけるを正しく扱う。
- [x] 予定入力を名前→日時→バッグ→詳細に。準備予測、同名履歴から入力、終了任意、終日、毎週複数曜日。カテゴリ単一、タグ色撤去、月次は新規作成対象から外す（既存記録は保護）。
- [x] 必要セットのチップ追加・除外、一時持ち物。曜日ごとのバッグ割当ルール。
- [x] クイック登録: 写真任意→名前→保存、任意バッグ、連続登録、バッグ/持ち物種別、アイコン自動。新規登録時に位置と基本セットを同時設定。
- [x] バッグ中身の共通画面: 入っている/足りない/場所別の外、検索、ピン、タップとPCドラッグ、Undo、複数移動、2バッグ移し替え。空セットへの初回移動だけピン。
- [x] 通知時刻、14日予定表、未来の位置をシミュレーションして差分のみ生成、NotificationScheduler。
- [x] Cloudflare Worker実装: 端末トークン認可、予定表全置換、削除、Cron、購読失効、再送、CORS。公開に必要なアカウント接続を確認。
- [x] Capacitorのローカル通知・自動バックアップ層、iOS雛形とCodemagic未署名ipa設定、SideStore手順。実機/外部ビルドの未検証部分は明記。
- [x] 色と文字・境界・状態のコントラストを高める。320px〜PC、キーボード、文字拡大、操作サイズを検証。
- [x] コア回帰・移行・自動完了・UI操作・オフライン・公開サブパスを検証。文書・配布手順・公開設定を新構成へ更新。
